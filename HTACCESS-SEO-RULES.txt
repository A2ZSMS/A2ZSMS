A2ZSMS – SEO rules for the live server's .htaccess
====================================================

WHY THIS IS A SEPARATE FILE
The live server already has an .htaccess (it may hold cPanel/PHP settings that
the contact forms need for /api/send-sms.php). Do NOT replace that file.
Paste the block below into it as described.

HOW TO APPLY (cPanel > File Manager > public_html > .htaccess, "Show hidden files")
1. Download a backup copy of the current .htaccess first.
2. Keep any cPanel blocks such as "# php -- BEGIN cPanel-generated handler" exactly as they are.
3. Remove the OLD rewrite rules that
     - send unknown URLs to index.html   (e.g.  RewriteRule . /index.html [L])
     - remove the trailing slash from URLs (e.g. RewriteRule ^(.*)/$ /$1 [R=301,L])
     - redirect https -> http or non-www -> www in separate steps
4. Paste the block below near the top (after any cPanel PHP block).
5. Test: https://www.a2zsms.in/this-does-not-exist/  -> must show the 404 page (status 404)
         https://a2zsms.in                          -> one redirect to https://www.a2zsms.in/
         https://www.a2zsms.in/about                -> redirects to /about/
         Submit a test form on /bulk-sms-service/   -> must still work
   If anything breaks, restore the backup.

----------------------------- COPY FROM HERE -----------------------------
Options -MultiViews
DirectoryIndex index.html index.php

RewriteEngine On

# 1) One single redirect to https://www (no http/non-www chains)
RewriteCond %{HTTPS} off [OR]
RewriteCond %{HTTP_HOST} !^www\.a2zsms\.in$ [NC]
RewriteRule ^(.*)$ https://www.a2zsms.in/$1 [R=301,L]

# 2) Leave real files (forms API, images, sitemap, etc.) alone
RewriteCond %{REQUEST_FILENAME} -f
RewriteRule ^ - [L]
RewriteRule ^api/ - [L]

# 3) Retired / duplicate URLs
RewriteRule ^home/?$ / [R=301,L]
RewriteRule ^refund-policie/?$ /refund-policy/ [R=301,L]

# 4) Add the trailing slash for pages that exist (site uses /page/ URLs)
RewriteCond %{REQUEST_URI} !/$
RewriteCond %{DOCUMENT_ROOT}%{REQUEST_URI}/index.html -f
RewriteRule ^(.*)$ /$1/ [R=301,L]

# 5) Real 404 for pages that do not exist (no more homepage-for-everything)
ErrorDocument 404 /404.html
